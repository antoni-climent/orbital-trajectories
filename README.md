# orbital-trajectories 

Orbital Trajectories is a minimal physics engine built with Godot that simulates Newton’s law of universal gravitation.
It allows you to create planets and spaceships, assign them initial velocities, and observe how gravitational forces affect their motion over time.
The goal of this project is educational.
